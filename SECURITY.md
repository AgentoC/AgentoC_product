# Security

Please report suspected security vulnerabilities privately to
`iamandyusuk@gmail.com`. Include the affected version, reproduction steps and
impact, but do not send production credentials or private user data.

The desktop host executes agent-directed work on the user's machine. Review
permissions and network exposure before using a deployment, and use isolated
accounts and workspaces when testing. The local web interface and remote or
paired access have different intended trust boundaries; consult the verified
deployment instructions for the version you use.

This document is a draft until the first public release and its supported
versions and reporting process have been confirmed.
