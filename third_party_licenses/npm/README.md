# Additional npm notices

These files supplement notices carried by installed npm packages. The
`agent-base`, `https-proxy-agent`, `data-uri-to-buffer`, `pg-types`, and `pgpass`
notices were extracted from the README shipped with the indicated version.

The `http_ece` notice comes from the original upstream v1.2.0 source tree,
commit `1da38132ad1f05480819129d8664a3256d09d7f0`, license blob
`d6a83c0df8d8f56a8d49f0b666f2033edd26cf18`.

The `abstract-logging` package's README links to its author's MIT license page.
The included transcription was retrieved on 2026-11-01; its displayed copyright
year is dynamic, so it should not be treated as the historical publication
year of version 2.0.1.

The `eastasianwidth` 0.2.0 npm metadata declares MIT, but its original source
tree does not include a separate license file. The included notice is from the
author's later upstream revision `1d41951a59d6`. Review the provenance of this
notice when preparing a binary distribution.

This directory is not a complete inventory of all release dependencies.
